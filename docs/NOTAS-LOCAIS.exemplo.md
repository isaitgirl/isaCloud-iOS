# Modelo de notas locais

Copie este arquivo para `isaCloud/local/NOTAS-LOCAIS.md` (pasta ignorada pelo Git) e preencha com os seus dados. **Não coloque valores reais neste modelo nem nos outros `.md` do repositório.**

O que costuma ficar nas notas locais:

- UDID dos seus aparelhos (`xcrun devicectl list devices` mostra o identificador).
- Números de pedidos e protocolos da Apple (Request IDs, tickets).
- Contas XMPP e servidores de teste.
- Onde estão os seus segredos (chaves de API, certificados, senhas): só o caminho, nunca o valor.

Nos documentos do repositório use marcadores como `<UDID_DO_IPHONE>` e aponte para as notas locais.
